# Contributing

This repository is a big-picture idea, not a specification everyone must follow.

Share perspectives, use cases, prototypes, and lessons from trying the approach. Different implementations are welcome. Explain what your work actually does and what remains an aspiration.

Use fictional examples when discussing personal context. Do not submit personal archives, private conversations, credentials, or other people's information.

Keep the main idea accessible. Detailed implementation guides belong in linked projects so readers can choose their own approach.
