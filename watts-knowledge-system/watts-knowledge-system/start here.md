# Start here

This is Derrick Watts's persistent knowledge system. It is built to ingest his systems, preserve provenance, and support investment research, forecasting, portfolio review, and critical analysis.

1. Read `AGENTS.md` and `ONBOARDING.md`.
2. Read `entities/workspace-now.md` and `entities/connection-inventory.md`.
3. Run `python3 scripts/validate.py --catalog` from this directory.
4. For first setup, follow `runbooks/hub-init.md`.
5. For investment work, load one role skill from `skills/roles/` and one playbook from `playbooks/`.
