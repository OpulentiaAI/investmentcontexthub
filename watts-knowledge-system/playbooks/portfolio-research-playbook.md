# Job
Produce evidence-gated investment research and paper-trading candidates.
# Process
1. Fix mandate and universe. 2. Run analyst signals with citations. 3. Construct conviction-weighted views. 4. Apply risk clamps. 5. Record thesis and cost ceiling.
# Output
Investment signals, decisions, forecasts, and scorecard receipts.
# Guardrails
Point-in-time honesty; no lookahead; LLM forms views, deterministic code sizes; no live trading.
